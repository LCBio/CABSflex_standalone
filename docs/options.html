2. Key Options Guide¶

This page explains the most common and important options for running CABS-flex. For a complete list of all available flags, see the Options Reference.

2.1 Input & Flexibility¶

Control how the protein is loaded and how rigid or flexible it should be.

Input Structure (-i)¶

  • Usage: CABSflex -i <pdb_code> or CABSflex -i <pdb_file>
  • Description: The only required argument. You can provide a 4-letter PDB code (downloaded automatically) or a local path.
  • Example: CABSflex -i 2gb1

Restraints Generation (-g)¶

  • Usage: --protein-restraints <mode> [<gap> <min_dist> <max_dist>]
  • Description: This is the most critical option for defining the protein's flexibility model. It generates distance restraints between C-alpha atoms.
  • Modes:
    • rigid (formerly all): Generates restraints for all residues. Results in a stiff model (good for checking local stability).
    • flexible (formerly ss2): Generates restraints only for secondary structure elements (helices/sheets). Loops remain free. This is the default.
    • plddt: Uses AlphaFold pLDDT scores (if available) to determine where to place restraints. High pLDDT = rigid, Low pLDDT = flexible.
    • none, unleashed or no-protein-restraints: No restraints generated.
  • Example (Rigid): CABSflex -i 1hpw --protein-restraints rigid 3 3.8 8.0
  • Example (Single Keyword): CABSflex -i 1hpw --protein-restraints flexible

Local Flexibility (-f)¶

  • Usage: --protein-flexibility <selection>
  • Description: Manually increase flexibility for specific regions (e.g., loops).
  • Example: CABSflex -i 1hpw -f flexible_regions.inp (where .inp file lists residues to loosen).

2.2 Simulation Control¶

Control the length and intensity of the simulation.

Temperature (-t)¶

  • Usage: --temperature <T_init> <T_final>
  • Description: Controls the thermal noise. Default is 1.4 1.4.
  • Higher Temperature: Try 2.0 2.0 to cross higher energy barriers or unfold regions.
  • Example: CABSflex -i 1hpw --temperature 2.0 2.0

Simulation Length (-a, -y, -s)¶

The total length of the simulation is determined by three parameters: - -a (Cycles): Number of annealing cycles (default: 20). - -y (Cycles per Step): Monte Carlo cycles (default: 50). - -s (Steps): Interval between saving frames (default: 50). - Total steps = a * y. - Increase length: To run 10x longer, increase -y to 500 (or -a to 200).
