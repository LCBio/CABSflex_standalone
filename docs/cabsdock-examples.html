CABS-dock Examples¶

1. Default Docking¶

To run CABS-dock using the default settings (recommended for inexperienced users):

CABSdock -i protein-pdb-code -p peptide-sequence:peptide-secondary-structure

For example, to dock the HKLVQLLTTT peptide (with predicted secondary structure CHHHHHHHCC) to chain A of PDB structure 2FVJ:

CABSdock -i 2FVJ:A -p HKLVQLLTTT:CHHHHHHHCC

This command will: - Load the conformation of chain A from 2FVJ as the protein structure - Load "HKLVQLLTTT" peptide sequence with the secondary structure assignment "CHHHHHHHCC" - Set default simulation settings (no knowledge about the binding site; almost rigid backbone of the protein receptor; random initial peptide conformations and positions)

To extend the outputs with contact maps, config saving, and simulation files:

CABSdock -i protein.pdb -p PEPTIDESEQUENCE -w dock_output

This will: * Load the protein structure from protein.pdb * Generate a random conformation and location for the peptide * Run 20 annealing cycles × 50 MC cycles = 1000 snapshots per replica * Use 10 replicas with Replica Exchange Monte Carlo * Save results in the dock_output directory

Example:
```bash
CABSdock -i 2FVJ:A -p HKLVQLLTTT:CHHHHHHHCC -M -C -S

2. Peptide Sequence from PDB¶

If the peptide sequence is available as a chain in the PDB database, it can be loaded directly. For example:

CABSdock -i 2BZW:A -p 2BZW:B

This loads chain A of 2BZW as the protein and the sequence of chain B as the peptide. Using this option does not bias the results — it does not load the secondary structure or conformation of the peptide.

3. Docking with Contact Information¶

It is possible to indicate preferred contacts for the modelled complex. These usually will be experimentally identified contacts expected in the resulting structures. Use --sc-rest-add (side-chain to side-chain) or --ca-rest-add (CA to CA) restraints.

Example — enforce contact between residue 235 from protein chain E and the 6th residue of the peptide:

CABSdock -i 2CPK:E -p TTYADFIASGRTGRRNAIHD:CHHHHHHHHCCCCCCCCCCC \
    --sc-rest-add 235:E 6:PEP 5.0 1.0

4. Flexible Protein Loops¶

CABS-dock allows increasing the flexibility of specified protein fragments — for example flexible loops covering the binding site in the unbound protein conformation.

Prepare a text file (flexibility.txt) specifying the flexible region and use the --protein-flexibility option:

CABSdock -i 2RTM:A -p HPQFEK:CHHHCC -f flexibility.txt

flexibility.txt contents (one line):

45:A - 54:A 0

5. Intrinsically Unstructured Protein Regions¶

The --protein-flexibility option may also be used to simulate intrinsically unstructured regions:

CABSdock -i 1Z1M:A -p RFMDYWEGL -f flexibility.txt

flexibility.txt contents:

1:A - 27:A 0
106:A - 119:A 0

This sets residues 1–27 and 106–119 as completely flexible.

6. Docking Multiple Peptides¶

To predict binding poses of systems with multiple interacting peptides, use the --peptide option multiple times:

CABSdock -i 1EJL:I -p 1EJL:A -p 1EJL:B

7. Modifying Protein Restraints¶

Protein rigidity can be adjusted to match experimental observations using --protein-restraints:

Compare RMSF results with: - default: --protein-restraints rigid 5 5.0 15.0 - --protein-restraints ss1 5 5.0 15.0 - --protein-restraints flexible 5 5.0 15.0

8. Sampling Near-Native Binding Modes¶

CABS-dock can explore near-native binding modes and bound complex dynamics. Load a bound complex using --add-peptide with keep keep flags, and set a lower maximum temperature:

CABSdock -i 1AWR:C -P 1AWR:I keep keep --temperature 1.2 1.0

9. Calculating Ligand-RMSD to a Reference Complex¶

Ligand-RMSD values can be automatically calculated using --reference-pdb. This also activates additional analysis procedures:

CABSdock -i 2FVJ -p HKLVQLLTTT:CHHHHHHHCC --reference-pdb 2FVJ:AB

where 2FVJ:AB is the reference protein-peptide complex. See Output & Analysis for the additional output.

10. Refinement with Rosetta FlexPepDock¶

CABS-dock models are reconstructed by default into all-atom representation using Modeller. Additional structure refinement can improve results. The pipeline below uses the high-resolution FlexPepDock protocol.

For individual cases, the online server is also available: http://flexpepdock.furmanlab.cs.huji.ac.il/

10.1 Input Preparation¶

You need at most 3 files: - model.pdb — CABS-dock resulting protein-peptide complex (required) - native.pdb — known complex structure (optional) - unbound.pdb — unbound receptor structure (optional)

In each file, keep only the ATOM section with receptor coordinates first, then peptide. Clean with:

~/Rosetta/tools/protein_tools/scripts/clean_pdb.py model.pdb A B
# Output: model_AB.pdb

If using a full atomic structure, steric clashes can cause bad rosetta energy. Solutions: 1. Cut Cα coordinates and reconstruct with another tool (PRODART, REMO, BBQ, SAABAC) 2. Use FlexPepDock with -min_receptor_bb for backbone minimization 3. Replace CABS-dock receptor coordinates with the free receptor structure (align first)

Aligning with theseus:

theseus -s0-120 -o model_AB.pdb unbound.pdb
# Output: theseus_sup.pdb (superposed unbound receptor)

Replace receptor coordinates:

~/Rosetta/tools/protein_tools/scripts/clean_pdb.py model_AB.pdb B    # cut peptide
cat theseus_sup.pdb model_AB_B.pdb > model.pdb                       # combine

10.2 Initial Prepack¶

~/Rosetta/main/source/bin/FlexPepDocking.linuxgccrelease \
    -database ~/Rosetta/main/database \
    -s model.pdb -flexpep_prepack -ex1 -ex2aro
# Output: model_0001.pdb
mv model_0001.pdb model_prepacked.pdb

10.3 FlexPepDock Refinement¶

Create flexpepdock.flagfile:

-nstruct 250
-in::file::s    /PATH/model_prepacked.pdb
-out:file:silent flexpepdock.silent
-out:file:silent_struct_type binary
-pep_refine
-ex1
-ex2aro
-use_input_sc
-unboundrot      /PATH/unbound.pdb

Run:

~/Rosetta/main/source/bin/FlexPepDocking.linuxgccrelease \
    -database ~/Rosetta/main/database @flexpepdock.flagfile

10.4 Extract Top Models¶

grep '^SCORE' flexpepdock.silent | cut -c 1-284,309- > tmp
cat tmp | sort -k1,1 -k2g > silent_scores.sc
cat silent_scores.sc | sort -k2g | awk '{print $47}' | head -11 | tail -10 > top10.tag
# Check that column 47 is 'description'

~/Rosetta/main/source/bin/extract_pdbs.linuxgccrelease \
    -in:file:silent flexpepdock.silent -in:file:tagfile top10.tag

11. Docking to GPCRs¶

A CABS-dock based protocol for modeling GPCR-peptide systems. See: Badaczewska-Dawid A, Kmiecik S, Kolinski M. Docking of peptides to GPCRs using a combination of CABS-dock with FlexPepDock refinement.

The protocol consists of three stages: 1. Docking with CABS-dock (peptide sampling restricted to relevant receptor fragments) 2. Reconstruction of atomistic structures from C-alpha traces using PD2 3. Refinement and scoring using Rosetta FlexPepDock

Stage 1: CABS-dock docking¶

CABSdock -s 100 -M -C -S -v 4 \
    -i 5GLH_struc.pdb:A -p 5GLH_struc.pdb:B \
    --reference-pdb 5GLH_struc.pdb:A:B \
    --ca-rest-add 1:PEP 15:PEP 5.3 1.0 \
    --ca-rest-add 3:PEP 11:PEP 6.2 1.0 \
    --sc-rest-add 249:A 1:PEP 30.0 5.0 \
    --sc-rest-add 249:A 2:PEP 30.0 5.0 \
    --sc-rest-add 249:A 3:PEP 30.0 5.0 \
    --sc-rest-add 249:A 4:PEP 30.0 5.0 \
    --sc-rest-add 249:A 5:PEP 30.0 5.0 \
    --sc-rest-add 249:A 6:PEP 30.0 5.0 \
    --sc-rest-add 249:A 7:PEP 30.0 5.0 \
    --sc-rest-add 249:A 8:PEP 30.0 5.0 \
    --sc-rest-add 249:A 9:PEP 30.0 5.0 \
    --sc-rest-add 249:A 10:PEP 30.0 5.0 \
    --sc-rest-add 249:A 11:PEP 30.0 5.0 \
    --sc-rest-add 249:A 12:PEP 30.0 5.0 \
    --sc-rest-add 249:A 13:PEP 30.0 5.0 \
    --sc-rest-add 249:A 14:PEP 30.0 5.0 \
    --sc-rest-add 249:A 15:PEP 30.0 5.0 \
    --sc-rest-add 249:A 16:PEP 30.0 5.0 \
    --sc-rest-add 249:A 17:PEP 30.0 5.0 \
    --sc-rest-add 249:A 18:PEP 30.0 5.0 \
    --sc-rest-add 249:A 19:PEP 30.0 5.0 \
    --sc-rest-add 249:A 20:PEP 30.0 5.0 \
    --sc-rest-add 249:A 21:PEP 30.0 5.0

Stage 2: PD2 reconstruction¶

~/bin/pd2_ca2main --database ./database/ \
    -i 5GLH_S1_M1.pdb -o 5GLH_S1_M1-reconstructed.pdb \
    --ca2main:new_fixed_ca --ca2main:bb_min_steps 500

Stage 3: Input preparation and FlexPepDock refinement¶

Remove side chains and reorder chains:

~/select_atoms.py -f 5GLH_S1_M1-reconstructed.pdb \
    -wc A,B -wa CA,CB,C,O,N -o 5GLH_S1_M1-backboneCB.pdb

Rename chains:

~/rename_chains.py -f 5GLH_S1_M1-backboneCB.pdb \
    -cho C,D -chn A,B -o 5GLH_S1_M1-chains.pdb

Clean and renumber:

~/Rosetta/tools/protein_tools/clean_pdb.py 5GLH_S1_M1-chains.pdb
mv 5GLH_S1_M1-chains_AB.pdb 5GLH_S1_M1-formated.pdb

Prepack:

~/Rosetta/main/source/bin/FlexPepDocking.linuxgccrelease \
    -database ~/Rosetta/main/database \
    -s 5GLH_S1_M1-formated.pdb -flexpep_prepack -ex1 -ex2aro
mv 5GLH_S1_M1-formated_0001.pdb 5GLH_S1M1.pdb

Refine:

~/Rosetta/main/source/bin/FlexPepDocking.linuxgccrelease \
    -database ~/Rosetta/main/database @flexpepdock.flagfile

flexpepdock.flagfile:

-nstruct 300
-in::file::native <path>/ref.pdb
-in::file::s      <path>/5GLH_S1M1.pdb
-out:file:silent flexpepdock-lowres.silent
-out:file:silent_struct_type binary
-detect_disulf true
-rebuild_disulf true
-fix_disulf <path>/disulfide.dat
-lowres_preoptimize true
-pep_refine
-ex1
-ex2aro
-use_input_sc

disulfide.dat:

293 307
295 303

Stage 4: Score and select models¶

# Extract and sort scores
cat flexpepdock.silent | grep "SCORE:" | head -1 | \
    awk '{for (i = 1; i <= NF; i++) print i, $i}' > p
t1=$(cat p | grep "reweighted_sc" | awk '{print $1}')
t5=$(cat p | grep "description" | awk '{print $1}')

# Select top models by reweighted_sc and pep_sc
# Extract PDBs
~/Rosetta/main/source/bin/extract_pdbs.linuxgccrelease \
    -database ~/Rosetta/main/database \
    -in:file:silent flexpepdock-lowres.silent -in:file:tagfile tags

Evaluate with DockQ:

~/DockQ/scripts/fix_numbering.pl model.pdb ref.pdb
~/DockQ/DockQ.py model.pdb.fixed ref.pdb > parameters.txt

Helper scripts (select_atoms.py, rename_chains.py) are available from the CABS-dock repository downloads.
