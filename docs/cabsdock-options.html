5.1 CABS-dock Options¶

Basic options¶

⬆ Back to top

Click on an option link to read full description

  • -i, --input-protein INPUT — Load input protein structure.
  • -p, --peptide PEPTIDE — Load peptide sequence.
  • -c, --config FILE — Read options from FILE.

Protein options¶

⬆ Back to top

Click on an option link to read full description

  • -e, --exclude RESIDUES — Exclude protein residues from the docking search.
  • --excluding-distance DIST — Set minimum distance between peptide and excluded residues.
  • -g, --protein-restraints MODE GAP MIN MAX — Generate protein distance restraints.
  • --no-protein-restraints — Do not automatically generate any protein restraints.
  • --protein-restraints-retain PERCENTAGE — Reduce the number of protein restraints.
  • --protein-plddt FLEXIBILITY — Read pLDDT values to modify flexibility.
  • --protein-category FLEXIBILITY — Modify category of flexibility.
  • -f, --protein-flexibility FLEXIBILITY — Modify flexibility of selected protein's residues.
  • --weighted-fit ARG — Set and customize structural alignment.
  • --gauss-iterations NUM — Set number of weighted-fit iterations.
  • --receptor-ss STR — Manually assign secondary structure.

Peptide options¶

⬆ Back to top

Click on an option link to read full description

  • -P, --add-peptide PEPTIDE CONFORMATION LOCATION — Add peptide with custom conformation and location.
  • -d, --separation DISTANCE — Set separation distance between peptide and protein.
  • --insertion-clash DIST — Set clash distance for building initial complex.
  • --insertion-attempts NUM — Set number of insertion attempts.
  • --pairmod FILENAME — Read pairwise potential weights from file.

Restraints options¶

⬆ Back to top

Click on an option link to read full description

  • --ca-rest-add RESI RESJ DIST WEIGHT — Add C-alpha distance restraint.
  • --sc-rest-add RESI RESJ DIST WEIGHT — Add SC distance restraint.
  • --ca-rest-weight WEIGHT_MIN WEIGHT_MAX — Set global C-alpha restraint weights.
  • --sc-rest-weight WEIGHT_MIN WEIGHT_MAX — Set global SC restraint weights.
  • --ca-rest-file FILE — Read C-alpha restraints from file.
  • --sc-rest-file FILE — Read SC restraints from file.

Simulation options¶

⬆ Back to top

Click on an option link to read full description

  • -a, --mc-annealing NUM — Set number of annealing cycles.
  • -y, --mc-cycles NUM — Set number of Monte Carlo cycles.
  • -s, --mc-steps NUM — Set number of MC steps between frames.
  • -r, --replicas NUM — Set number of replicas. (default: 10)
  • -D, --replicas-dtemp DELTA — Set temperature increment between replicas.
  • -t, --temperature TINIT TFINAL — Set temperature range. (default: [2.0, 1.0])
  • -z, --random-seed SEED — Set random seed.
  • -b, --binding-interactions FACTOR — Scale inter-chain interactions.
  • --disable-centro — Disable centrosymmetric potential.

All-atom reconstruction options¶

⬆ Back to top

Click on an option link to read full description

  • -A, --aa-rebuild — Rebuild final models to all-atom.
  • --aa-method ARG — Set reconstruction method.
  • --cg2all-env-prefix DIR — Path to cg2all environment.
  • -m, --modeller-iterations NUM — Set MODELLER iterations.

Analysis options¶

⬆ Back to top

Click on an option link to read full description

  • -R, --reference-pdb REF — Load reference complex structure.
  • -k, --clustering-medoids NUM — Set number of clustering medoids.
  • --clustering-iterations NUM — Set clustering iterations.
  • -n, --filtering-count NUM — Set number of models for clustering.
  • --filtering-mode MODE — Choose filtering mode.
  • -M, --contact-maps — Store contact maps.
  • -T, --contact-threshold DIST — Set SC contact distance.
  • --contact-threshold-aa DIST — Set heavy-atom contact distance.
  • --contact-map-colors CLR1 ... CLR6 — Set contact map colors.
  • --align METHOD — Select alignment method.
  • --align-options KEY=VAL — Set alignment options.
  • --align-peptide-options KEY=VAL — Set peptide alignment options.

Output options¶

⬆ Back to top

Click on an option link to read full description

  • -S, --save-cabs-files — Save CABS simulation file.
  • -L, --load-cabs-files FILE — Load CABS simulation data.
  • -C, --save-config — Save config file.
  • -o, --pdb-output SELECTION — Select PDB output.
  • --pdb-bfac-output SELECTION — Select beta-factor output.
  • --csv-output SELECTION — Select CSV output.
  • --json-output — Store JSON numeration.
  • --dssp-output — Store DSSP output.
  • --ss-output — Store secondary structure.
  • --restraints-output — Store restraints.
  • --renumber-residues-to-original — Renumber residues.

Miscellaneous options¶

⬆ Back to top

Click on an option link to read full description

  • -w, --work-dir DIR — Set working directory.
  • --fortran-command PATH — Path to fortran compiler.
  • --image-file-format FMT — Set image format.
  • --pdb-cache-dir DIR — Set PDB cache directory.
  • -v, --verbose LEVEL — Set verbosity level.
  • --log — Redirect output to log file.
  • --version — Print version.
  • -h, --help — Print help.
