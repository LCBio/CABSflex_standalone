Welcome to the CABS-flex and CABS-dock wiki! This documentation covers the standalone packages for protein flexibility analysis and peptide-protein docking.

Quick Start¶

CABS-flex is an efficient tool for fast simulation of protein structure flexibility, using a coarse-grained protein model to explore the conformational space of globular proteins. CABS-dock extends this simulation engine to enable flexible peptide-protein docking without prior knowledge of the binding site, allowing for significant structural rearrangements during the docking process.

Installation instructions and method outlines are provided on the Installation page.

CABS-flex has been successfully applied to a diverse range of biological problems, demonstrating its utility beyond standard flexibility simulations. The method provides essential validation for structural models (e.g., AlphaFold2, NMR) against experimental data and characterizes dynamic protein-protein interfaces, such as those in the SARS-CoV-2 Spike protein. By mapping conformational landscapes, it identifies allosteric communication pathways invisible in static structures and enhances the prediction of aggregation-prone regions. Additionally, CABS-flex facilitates the de novo structure prediction of linear and cyclic peptides, offering a rigorous, physics-based complement to deep learning approaches. For detailed protocols and results, see Applications & Case Studies.

Standard Use Case¶

To run a standard simulation (reproducing the behavior of the CABS-flex web server), simply provide your PDB file:

CABSflex -i 1hpw.pdb

Or use a PDB code to download it automatically:

CABSflex -i 1hpw

This will: 1. Run the simulation using default settings (optimized for globular proteins). 2. Generate a trajectory and 10 representative models. 3. Save user-friendly output in your working directory.

Flexibility Modes (-g)¶

The most important option is -g (or --protein-restraints), which defines the protein flexibility model.

Mode Description
flexible (Default) Restraints only on secondary structure (helices/sheets). Loops are free.
rigid Restraints on all residues.
plddt Uses AlphaFold confidence scores (pLDDT) to assign rigidity.
unleashed No restraints generated.

Example:

CABSflex -i 1hpw.pdb -g rigid  # Run a rigid simulation

  • Flexible mode applies distance restraints only to residues forming secondary structure elements, allowing greater flexibility in loops and unstructured regions. Previously referred to as ‘SS2’ in earlier versions of CABS-flex 2.0 (Nucleic Acids Res 2018) and standalone application (Bioinformatics 2019), it provides a balanced representation of protein dynamics. This mode has been validated against crystallographic B-factors and atomistic MD simulations using various force fields (J Chem Theory Comput 2013), NMR ensembles (Bioinformatics 2014), as well as in numerous structure–flexibility-function studies supported by experimental evidence, including Cryo-EM–derived conformational variability and functional analyses related to aggregation propensity and S-nitrosylation sensitivity (Protein Sci 2024). Importantly, the ability of the CABS model to predict loop structures ab initio has been demonstrated across various protein systems [BMC Struct Biol 2010, Biophys J 2014], including in the context of peptide interactions (Methods 2016), highlighting its suitability for modeling local structural variability.

    Specific example and outputs for simulation in flexible mode is provided on the Flexibility Modes page.

  • Rigid mode imposes uniform restraints on all residues, minimizing fluctuations throughout the structure. Equivalent to the ‘All’ mode described previously [Nucleic Acids Res 2018, Bioinformatics 2019], it effectively preserves native-like conformational constraints. Benchmarking with CHARMM36m-based ATLAS MD simulations showed high correlation with MD-derived fluctuation profiles, particularly in structured, globular proteins (Comput Struct Biotechnol J 2024). It is worth noting that the selection criteria of the ATLAS dataset favor well-folded, high-resolution monomeric proteins, which may bias the dataset toward more structurally stable and less flexible systems. However, some degree of intrinsic flexibility is still likely present in the selected structures.

    Specific example and outputs for simulation in rigid mode is provided on the Flexibility Modes page.

  • pLDDT mode improves flexibility predictions by integrating structural confidence into the simulation process. In this mode, restraint strength is modulated according to per-residue pLDDT scores and secondary structure classification, as introduced in our recent work (Comput Struct Biotechnol J 2024). It is applicable when pLDDT scores are available, as in AlphaFold-predicted structures. Users may supply pLDDT values either through the B-factor field in the PDB file or via an external .json or .tsv file. Based on general observations, the overall level of flexibility generated by this mode tends to be closer to Rigid than Flexible, which is reflected in the naming convention, and the mode has been validated using ATLAS MD simulation data (Comput Struct Biotechnol J 2024).

    Specific example and outputs for simulation in pLDDT mode is provided on the Flexibility Modes page.

  • Unleashed mode applies no restraints, allowing for fully unrestricted conformational sampling. The resulting ensemble is governed solely by the intrinsic properties of the CABS coarse-grained force field. This mode is designed as an advanced option, recommended primarily for exploratory simulations where it is important to observe the behavior of a system in the complete absence of restraints. While this mode typically shows lower agreement with MD-derived fluctuation profiles and may produce exaggerated motions, it is valuable for modeling folding/unfolding processes or large-scale transitions in disordered or flexible systems. In such cases, meaningful results may require careful tuning of additional simulation parameters, such as temperature and number of cycles. The applicability of CABS-based simulations to disordered and unfolded protein systems has been reviewed in our previous work (Int J Mol Sci 2019), which discusses several case studies involving disordered binding partners and unstructured regions.
