Installation¶

This page provides instructions for installing the CABS-flex/CABS-dock standalone package.

1. Prerequisites¶

Before installation, ensure you have the following:

  • Linux OS (recommended) or macOS.
  • Windows (via WSL 2 — see below).
  • Bash shell.
  • Git (for repository access).
  • Micromamba or Conda (Anaconda or Miniconda).

    [!NOTE] The installer automatically bootstraps a standalone Micromamba binary if no environment manager is found. You do not need to pre-install Conda.

Windows Support (WSL 2) Tips¶

For Windows users, it is mandatory to use the Windows Subsystem for Linux (WSL 2). Native Windows Python is not supported.

How to enable WSL 2: 1. Open PowerShell as Administrator. 2. Run the command: wsl --install 3. Restart your computer. 4. Search for "Ubuntu" in the Start menu to open the Linux terminal. 5. Set up your Linux username and password. 6. Proceed with the Standard Installation below within this Ubuntu terminal.

WSL Optimization Tips: 1. Memory Allocation: All-atom reconstruction (cg2all) is memory intensive. If you experience crashes, ensure your .wslconfig (in %USERPROFILE%) allocates at least 8GB-12GB of RAM. ini [wsl2] memory=12GB 2. Filesystem Performance: For maximum performance, clone and run CABS-flex from the native Linux filesystem (e.g., ~/projects/) instead of the Windows mount (/mnt/c/...). 3. Shell Job Control: If running custom test scripts or parallel wrappers, enable monitor mode (set -m) to ensure jobs surveillance works correctly in non-interactive shells.

2. Standard Installation (Recommended)¶

This method uses Micromamba (or Conda) to manage the environment. The installer automatically sets up a dual-environment system to ensure stability for reconstruction.

Step 1: Run Installer¶

  • Remote Install: Replace YOUR_TOKEN with your GitHub Personal Access Token (PAT). bash curl -sSL https://raw.githubusercontent.com/LCBio/cabsflex/main/install.sh | bash -s YOUR_TOKEN
  • Local Install: If you have already cloned the repository, run from the root: bash bash install.sh

Step 2: Configure Modeller (Optional)¶

During installation, you will be prompted for your MODELLER license key. - If provided, the installer will automatically locate and patch the configuration. - The installer now uses micromamba run to precisely detect the config file, handling differences between Modeller 10.x versions.

Step 3: Activate and Use¶

The installer creates: 1. cabs: Main environment for simulations. 2. cabs_reconstruct: Segregated environment for cg2all reconstruction.

Activate the main environment:

micromamba activate cabs
# OR
conda activate cabs

The path to cabs_reconstruct is automatically saved in the configuration, so you don't need to activate it manually.

You can now use CABSflex and CABSdock commands.

3. HPC / Source Installation (Venv)¶

For users on High-Performance Computing (HPC) clusters or those who prefer installing from a local source using virtual environments.

Step 1: Identify and Load Modules¶

HPC environments use environment modules. Before installing, identify the compatible versions of GCC and Python:

module avail GCC
module avail Python
module load GCC/13.2.0 Python/3.11.5

Tip

Always run the installation from a **worker node** (via `srun --pty bash -i`) to ensure access to all resources and avoid login node restrictions.

Step 2: Filesystem Check¶

  • HOME: Usually persistent but limited in space.
  • SCRATCH: Fast, high-capacity, but temporary. Use it for TEMP_ROOT in the script.
  • BASE_INSTALL_DIR: Where the virtual environment will live (e.g., inside your home directory or in persistent storage allocated for your project).

Step 3: Clone and Configure¶

git clone https://github.com/LCBio/cabsflex.git
cd cabsflex

Edit the CONFIGURATION SECTION at the top of install-hpc.sh: - BASE_INSTALL_DIR: Where the virtual environment will live (e.g., inside your home directory or in persistent storage allocated for your project). - MODELLER_KEY: Your license key (see below). - TEMP_ROOT: Set to your cluster's high-speed scratch directory.

Step 4: Run the Local Installer¶

bash install-hpc.sh

Step 5: Activate¶

source path/to/your/venv/bin/activate

4. Optional Dependencies¶

MODELLER (Optional)¶

CABS-dock can use MODELLER as an alternative to cg2all for all-atom reconstruction. While the installer downloads the package, you must provide a license key for it to work. - Get a key: Register at https://salilab.org/modeller/registration.html (free for academic use). - Configure for Conda: Once the environment is created, you may need to add the key to the license file: bash # Locate the config file automatically MOD_CONFIG=$(micromamba run -n cabs python -c "import modlib.modeller.config as c; print(c.__file__)") # Set the license sed -i "s/license = .*/license = r'YOUR_KEY'/" $MOD_CONFIG

cg2all¶

The default all-atom reconstruction tool used in CABS-flex and CABS-dock. The HPC installer sets this up automatically in a segregated environment to avoid dependency conflicts.

5. Troubleshooting & FAQ¶

Issue Likely Cause Solution
Permission Denied (Git) Invalid or expired token Ensure your PAT has repo access and hasn't expired.
MODELLER ImportError License key missing Follow the instructions in Section 4 to add your key.
Disk Quota Exceeded Large temporary files Set the TMPDIR environment variable to a scratch partition.
Build Error: setuptools Legacy test residues The installer now cleans tests/test_cli_options/ before build. Run git clean -fdx if persists.
Micromamba: Download failed Network/SSL Ensure curl is installed and has internet access.
Invalid License Key Missing 'r' prefix Use license = r'KEY' in config.py. The installer does this automatically.
WSL OOM / Crash RAM Exhaustion Increase memory in .wslconfig (see Section 1).
---

6. Verification¶

Verify the installation:

CABSflex --help
CABSdock --help

If the commands are recognized and display the help message, the installation was successful.
