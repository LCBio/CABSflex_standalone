# CABS-flex Beta Testing Guide

Thank you for participating in the CABS-flex private beta!

## 📋 Testing Checklist

### Installation
- [ ] `conda env create -f environment.yml`
- [ ] `conda activate cabs`
- [ ] `pip install -e .`
- [ ] `CABSflex --help` works
- [ ] `CABSdock --help` works

### Functionality
- [ ] Test your specific use cases
- [ ] Try different input formats
- [ ] Check output quality

## 🐛 Reporting Issues

Please include:
- **Platform**: OS, Python version, conda version
- **Steps to reproduce**
- **Error messages** (full traceback)
- **Expected vs actual behavior**

## 💬 Contact

- **Issues**: Use the [GitHub Issue Tracker](https://github.com/LCBio/CABSflex_standalone/issues) for bugs and feedback.
- **General Inquiries**: Visit our [Contact Page](https://lcbio.pl/contact-us/).

Thank you for helping improve CABS-flex! 🧬
